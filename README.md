# SpamSMS (Native Android)

Detta projekt är migrerat från Expo till ren React Native CLI för Android.

## Vad appen gör

- Läser kontakter (med tillstånd)
- Låter dig skriva ett meddelande
- Öppnar telefonens inbyggda SMS-app med mottagare + text förifyllt

Ingen bakgrundsskickning eller automatiska massutskick används.

## Krav

- Node.js 20+
- Android SDK/adb korrekt installerat
- Emulator eller fysisk Android-enhet

## Installation

```bash
cd spamsms
npm install
```

## Kör appen

```bash
npm run android
```
